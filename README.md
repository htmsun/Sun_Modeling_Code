This repository contains the Python code used to model two- and three-cell Notch-Delta lateral inhibition and generate figure panels in the submitted manuscript, 
"Organ injury accelerates stem cell differentiation by modulating a fate-transducing lateral inhibition circuit".

"Updated_2CellModel.py" contains code used to generate panels in Fig. 3 and Fig. S5.

"Updated_3CellModel.py" contains code used to generate figure panels in Fig. S6.
